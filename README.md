## Current research

**Can delay and cost overrun in public works be predicted before funding is approved?**
For my PhD I built an audited Python pipeline linking 108,608 EU cohesion-fund records (OpenCoesione and OpenCUP) and modelled the 33,929 public works among them with CatBoost and SHAP.

- Trained on projects up to 2017 and tested on 2018–2020: 48% of the projects the model ranked in its riskiest 10% were delayed or over budget, against 35% across all projects (AUC 0.57, against 0.50–0.53 for budget-only rules).
- A separate model that knows only each project's funding programme reaches AUC 0.70, so early risk screening should start at programme level.

The thesis code is private until the defence.
